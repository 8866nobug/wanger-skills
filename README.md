# wanger-skills

My personal collection of AI skills for Claude Code. 每个子目录是一个独立 Skill（含 `SKILL.md`）。

## Skills

| Skill | 说明 | 文档 |
|---|---|---|
| `excalidraw` | 用自然语言生成、校验和增量修改 Obsidian / 标准 Excalidraw 图表。 | [README](excalidraw/README.md) |

## 使用

```bash
git clone https://github.com/8866nobug/wanger-skills.git ~/.claude/skills
```

已有 `~/.claude/skills` 时，把需要的 Skill 子目录复制进去即可。
