# 布局与间距规范

## 1. 默认尺寸（styles.py）

| 类型 | 宽 | 高 |
|---|---|---|
| process | 200 | 60 |
| decision（菱形） | 240 | 120 |
| terminator（椭圆） | 160 | 60 |
| uml_class | 200 | 120 |
| entity | 按内容（最小 240） | 46 + 字段数 × 30 + 14 |

## 2. 间距

- 纵向节点间距（中心距）`VGAP = 90`；横向 `HGAP = 80`。
- 分支/判断节点预留更大间距；画布范围由布局结果确定。

## 3. 布局算法

- `vertical_flow`：自上而下线性布局（无边节点时缺省）。
- `horizontal_flow`：自左向右线性布局。
- `flow`：**分层流程布局**（有边时缺省）——行按最长路径（拓扑序）确定；每行节点列 = 相邻层节点列的中位数（barycenter/median），再按该值排序、贪心拉开相邻间距；随后上下扫描 4 轮，取边交叉数最少的一轮。
- `er_layout`：**ER 布局**（含 `entity` 时缺省）——按连通分量分组；每个分量以度数最高的实体为根做无向 BFS，层号即列号；列内按邻居位置中位数排序 3 轮；列宽/行高按实际卡片尺寸计算，短列垂直居中；分量按大小排序后从左到右铺开，超过 `ER_MAX_ROW_W` 自动换行。
- `grouped_layout`：**分组布局**（含 `group` 时缺省）——先把每个组的成员分成一个块，组内复用 `er_layout`（含 entity）或 `flow`/`vertical_flow`；未分组节点先放一块，再按 spec 顺序摆放组块；组间用 `GROUP_GAP`，超过 `ER_MAX_ROW_W` 换行。跨组边不参与组内排序。
- 经典 Chen 概念图：实体矩形直接参与 `er_layout` / `grouped_layout` 排布（不再有属性环）。实体列间距按最大菱形宽度放大，同列行距按“从同一实体扇出的相邻菱形中点至少要隔开一个菱形高度”推导，避免联系菱形压住实体或互相重叠。菱形先取两端实体空隙的中点，再以 `CHEN_SEARCH_STEP` 为步长、沿实体连线方向/垂直方向做 AABB 冲突避让（实体、已放菱形、组标题、旁注），并检查菱形到两端实体的连线不穿过其他实体（`_segment_hits_box`）；同一对实体的多条联系沿垂直方向错开；自关联菱形绕实体旋转搜索空位；基数标签在实体端附近按“沿连线 × 垂直连线”候选位置搜索，避开实体、菱形和其他标签。分组模式下组块四周预留 `content_margin`，组框随后扩大包住组内联系菱形。
- `count_crossings`：按最终坐标统计边交叉数（测试/诊断用）。
- `bounds`：计算元素包围盒（用于旁注列定位与画布范围）。
- 旁注（`note`/`text`）放置在主图右侧独立列（`NOTE_GAP` 水平间距）；含 `entity` 的 ER 图用 `ER_COMPONENT_GAP`，给右侧自关联回环留空间。
- 图标题（spec `title`）居中放在主图上方，字号 `TITLE_FONT_SIZE=28`，与主图顶部间距 `TITLE_GAP=36`；不参与节点布局，`patch` 后会重新对齐到主图上方。
- 布局返回每个节点的左上角坐标；`builder.build_diagram` 缺省用 `flow`（有边）/ `vertical_flow`（无边）。
- `patch` 默认**不做布局**：沿用现有元素坐标，新节点放到现有内容右侧；`--relayout` 才重新执行上述布局。

## 4. ER / 分组布局参数

| 常量 | 值 | 含义 |
|---|---|---|
| `ER_HGAP` | 170 | 列间距（表卡片之间留出正交连线通道） |
| `ER_VGAP` | 60 | 同列上下间距 |
| `ER_COMPONENT_GAP` | 240 | 连通分量 / ER 旁注列间距 |
| `ER_MAX_ROW_W` | 2800 | 分量 / 组块换行宽度 |
| `ER_TOUCH_GAP` | 2 | ER 连线端点距卡片边缘（几乎贴边） |
| `GROUP_PAD` | 24 | 组容器内边距 |
| `GROUP_HEADER_H` | 44 | 组容器标题区高度 |
| `GROUP_GAP` | 90 | 组容器之间的间距 |
| `GROUP_MIN_W` | 240 | 组容器最小宽 |
| `GROUP_TITLE_FONT_SIZE` | 18 | 组标题字号 |
| `CHEN_ENTITY_MIN_W` / `CHEN_ENTITY_H` | 140 / 60 | Chen 实体矩形最小尺寸 |
| `CHEN_REL_MIN_W` / `CHEN_REL_MIN_H` | 130 / 90 | 联系菱形最小尺寸 |
| `CHEN_REL_CLEARANCE` | 24 | 菱形与实体/菱形之间的最小间距 |
| `CHEN_LABEL_CLEARANCE` | 6 | 基数标签与其他元素的最小间距 |
| `CHEN_SEARCH_STEP` / `CHEN_SEARCH_RINGS` | 12 / 60 | 冲突避让搜索步长与最大搜索环数 |

## 5. 已知限制

- 交叉最小化是启发式，不保证全局最优；复杂图建议生成后手动微调。
- 循环/回边节点会落到最末行，不做弧线回绕。
- 列宽按全图最大节点宽统一，窄图会略显稀疏。
- ER 正交连线在跨多列的远距离边上可能穿过中间列的表卡片；不做绕行轨道（track）路由。
- ER 同一侧的多个连接点按对端坐标排序分散，极端密集（单侧 >6 条边）时仍可能显得拥挤。
- `group` 只支持一层；跨组边不参与组内排序，可能穿过组背景框或组内其他卡片。
- 组内自关联节点只做“排到成员列表末尾”的启发式，复杂组内仍可能需要手动调整。
- 经典 Chen 概念图不生成属性；为保证菱形和基数标签不重叠，列距/行距会明显大于普通 ER 图，画布更大。跨域联系菱形不属于任一分组；冲突避让只处理实体/菱形/标签的包围盒重叠，不消除连线交叉；交叉只做启发式规避和 warning 提示，复杂业务图仍可能需要手动微调。
